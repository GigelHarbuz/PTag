# Tutorial cu instalare de la 0

## Pasul 1 - downloadeaza clientul Proxmark
- Intra pe [proxmarkbuilds.org](https://www.proxmarkbuilds.org/)
- Descarca "Latest RRG / Iceman generic build for Proxmark3 devices (non RDV4), for Proxmark3 Easy, RDV1, RDV2, RDV3, etc etc"
- Asteapta sa se descarce.

## Pasul 2 - extractarea si creearea folderului

 **Ai nevoie de Winrar/ 7zip !!**

- Creeaza un folder numit "Proxmark"/"Cartele" sau cum vrei tu pe Desktop
- Deschide fisierul .7z descarcat
- Apasa pe "Extract all", si selecteaza folderul facut
- Asteapta sa se extracteze.

## Pasul 3 - flashuirea Proxmarkului
Urmareste acest videoclip:
#### [Tutorial flash](https://www.youtube.com/watch?v=n1Xt-1ZmjM0)
Partea cu "hw tune" de la final nu este necesara!

## Pasul 4 - instalarea Python
- Intra pe site-ul Python la sectiunea de downloads: [python.org/downloads](https://www.python.org/downloads/)
- Apasa pe "Or get the standalone installer for **Python 3.1x.x**"
- Asteapta sa se downloadeze
- Apoi instaleaza-l din fisierul descarcat.
